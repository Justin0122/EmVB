# @perkyzz/emvb-icons

The icon sets for the [EmVB](https://emvb.dev) editor's Icon library: Lucide, Font Awesome Free, Tabler and Remix Icon, as compact JSON. `@perkyzz/emvb` depends on this package; you don't install or import it yourself.

Only the editor loads these files. When an editor picks an icon, its SVG is stored with the page, so public pages never load an icon set.
